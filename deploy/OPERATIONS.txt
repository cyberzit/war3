Implemented API:
  POST /api/auth/register      username (3-24 letters/digits/_), password 10-128
  POST /api/auth/login         returns bearer token; 7 day expiration
  POST /api/auth/logout        revokes current bearer token
  GET/POST /api/rooms          list/create rooms (authenticated)
  POST /api/rooms/{id}/join
  POST /api/rooms/{id}/heartbeat  host renews every 30s; room expires after 120s
  POST /api/rooms/{id}/leave      host leaving closes room
  GET/POST /api/rooms/{id}/messages  members only; last 100 retained
  Message polling supports ?after=<message id>. No WebSocket yet.
Passwords use individual random salts and scrypt; only token hashes stored.
Request body and rate bounds, member/host authorization and room capacity checks.
